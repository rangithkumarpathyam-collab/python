# 📚 AI Study Buddy

An interactive learning assistant built with Streamlit and Google Gemini API.

## ✨ Features

- **AI Chatbot**: Ask questions about various subjects (C Programming, Python, Java, Data Structures, DBMS, Computer Networks, Operating Systems) and receive concise, easy-to-understand explanations with examples.
- **AI Quiz Generator**: Generate customized multiple-choice questions (MCQs) for any selected subject with answer keys and explanations.

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rangithkumarpathyam-collab/python.git
   cd python
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Set up environment variables:
   - Create a `.env` file in the project root:
     ```env
     GEMINI_API_KEY=your_gemini_api_key_here
     ```

4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
